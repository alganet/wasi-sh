wasi-sh: host builtins

The shell resolves a command name against its functions, its builtins and the busybox applet table — and then, if the embedder registered one, a host builtin: a JS function that takes argv and returns an exit status. In-process, like an applet, and just as much not a process.

Two are registered in examples/host-builtins.worker.mjs: json pulls a value out of JSON by dotted path (the guest has no JSON parser; the host always had one), and num formats numbers for a locale. Both are ordinary filters, so both compose:

cat /data/repo.json | json stars | num  ·  json name /data/repo.json  ·  type json
